CSV Formatting Guidelines

Best practices for seamless high-throughput screening

Column Headers

The file must include a column titled smiles or SMILES. Additional columns (like molecule_name or id) are safely preserved.

Batch Limit & Speed

Up to 2,000 compounds can be processed in a single run. Larger files are automatically capped at row 2,000 to ensure fast web response times.

Error Resilience

Invalid SMILES syntax will be flagged as Invalid in the results table without aborting the entire screening batch.
